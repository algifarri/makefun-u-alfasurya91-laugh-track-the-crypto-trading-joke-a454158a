One funny line about crypto trading life, at most 200 characters. A judge model compares entries two at a time and the funniest line takes the reward: the top 10 lines share $2, and entry is free.

## Run it

```sh
python3 main.py
```

The program writes one funny line (73 characters) to `/output/entry.txt`:

> I set an alarm for 3am to check the chart. The liquidation beat me to it.
